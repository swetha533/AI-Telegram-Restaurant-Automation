# 🍽️ AI Telegram Restaurant Automation

## 📌 Project Overview
This project is an AI-powered Restaurant Automation System developed using n8n, Telegram Bot, Google Gemini AI, and Google Sheets.

The chatbot helps customers:
- View restaurant menu
- Check food availability
- Get food prices
- Place food orders
- Receive AI-generated responses automatically

---

## 🛠️ Technologies Used

- n8n
- Telegram Bot API
- Google Gemini AI
- Google Sheets
- Ngrok

---

## 🔄 Workflow

        ▼
